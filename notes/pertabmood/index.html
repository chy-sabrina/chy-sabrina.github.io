[build] pertabmood

Some notes from building PerTabMood.

Background

I usually prefer dark mode, but some ChatGPT-generated visualizations are difficult to read because of their colors. For example, light backgrounds with white text can have poor contrast.

I wanted to switch that particular ChatGPT tab to light mode to make the visualization easier to read. However, ChatGPT's theme setting also affects my other open ChatGPT tabs, which I still want to keep in dark mode.

This inspired me to build PerTabMood, a browser extension that lets me switch between light and dark mode independently for each tab.

Implementation

I built PerTabMood as a Manifest V3 extension for Chromium-based browsers, using AI assistance throughout development. It uses the Chromium Debugger API to emulate a tab-specific color-scheme preference rather than simply inverting page colors.

Challenges and Limitations

My initial instructions were not specific enough, so the first version generated by AI worked more like a color inverter. During testing, I noticed that it also inverted the colors of the emojis, which was not the behavior I wanted.

I refined the approach to emulate the browser's prefers-color-scheme preference for each tab instead of forcibly inverting page colors. This allows websites that support light and dark themes to respond more naturally to the selected preference.

However, PerTabMood cannot guarantee that every website will change its appearance. It only emulates the browser's color-scheme preference; a website may use its own theme setting instead. The extension also relies on Chromium's Debugger API, which can encounter permission restrictions or conflicts with DevTools.
